Connect a booth printer

Run the PrintNode Client on the booth computer with the actual 4×6 printer configured. Choose the printer here to enable queued printing after a guest saves a photo.

Printer integration requires a PrintNode API key configured on the server.

Partner API access

Use a server-side API key to create events from an existing photo booth software platform. Never place this key into public JavaScript or an iframe.
