# EVERAFTER STUDIO
### Every guest gets their moment. Every booth operator gets a premium upgrade.

**THE PROBLEM**  Wedding guests often never have a chance for a photo with the couple. A traditional booth captures guests alone; EverAfter produces a *clearly edited* photo with the couple's real wedding-day portrait.

**THE EXPERIENCE**  The operator photographs the newlyweds in three poses once. A guest walks up, chooses a pose, takes a half- or full-body photo, and the booth removes the guest's background before compositing them into the couple's scene. The guest leaves with a 4×6 print or private QR gallery link. Add a second guest to make it a group keepsake.

**WHY OPERATORS CARE**  A new paid add-on without replacing the kiosk, camera or 4×6 printer; separate events; event-branded experiences; secure private delivery; booking inquiry and deposit workflow; embed/partner API access for integrators.

## Proposed B2B packaging (test willingness to pay; NOT verified market pricing)

| Pilot product | Suggested test price | Included |
|---|---:|---|
| Per-event operator license | $79–$149 / wedding | Booth URL, 3 couple poses, QR gallery, downloads |
| Studio Partner monthly | $199–$399 / month | Multiple wedding events, operator dashboard, branded booths |
| Custom white-label integration | Quoted | Approved embedding, hardware onboarding, API keys |

**Sell-to-operator discovery questions:** How many weddings per month? Existing booth OS / printer hardware? Guests per wedding? Internet reliability? Current add-on pricing? Who is the data controller? Would customers pay for a realistic composite versus a playful AR sticker? What photo-quality threshold would trigger a refund?

**Pitch:** “Capture the couple once. Give every guest their moment. EverAfter adds a premium group-portrait experience to your existing booth hardware, with an operator dashboard, private QR delivery and optional 4×6 printing.”

**What not to promise yet:** Perfect realism; 100% automatic cuts on all hair/backgrounds; offline AI; unsupported cameras; guaranteed printing or payment flow without onboarding; full live AR; platform reliability SLA. The platform is a commercial pilot until hardware validation, external integration tests, privacy/legal documentation and event load tests are complete.

## Installation paths

**Easy:** Booth operator opens the event URL full-screen in a supported kiosk browser (HTTPS, web camera). Print by browser or linked PrintNode client.

**Integrated:** Booth partner embeds the event iframe into its own touch UI (approved origin, camera permission). Backend integration uses one-time-issued secret API key to create events from the partner's CRM/booking system. Implement partner webhooks, custom branding and per-tenant subscription billing before a large reseller program.

## Recommended first pilot terms

- 1 wedding/closed test; 1 operator; max ~30 guest groups; operator present throughout
- Bride/groom approve exact photographs and informed editing; guests consent before export/save
- 4×6 printer physical calibration, backup paper/ink, manual upload fallback
- Clear photo retention period and contact for deletions
- Photo quality approval and refund policy before accepting paid event commitments
- Collect operator feedback on integration time, guest session duration, print failures, image quality, and actual willingness to pay
